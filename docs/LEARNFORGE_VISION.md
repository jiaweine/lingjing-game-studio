# LearnForge 灵境教育智能体方向

## Positioning

LearnForge is an education domain built on top of the self-evolving harness architecture.

The goal is not a simple answer engine. The system learns how to teach a learner better through verified learning outcomes.

## Core loop

```
Learner State
    -> Diagnosis
    -> Pedagogical Action
    -> Learning Verification
    -> Memory
    -> Harness Evolution
```

## Frozen Kernel

The following capabilities remain protected:

- learner state ownership
- assessment integrity
- safety constraints
- held-out evaluation
- promotion transaction

## Evolvable Surface

The following can evolve:

- teaching strategies
- skill composition
- agent topology
- memory policies
- curriculum policies
- model routing

## Initial MVP

First domain:

- middle school mathematics
- wrong answer diagnosis
- personalized explanation
- adaptive practice
- delayed verification

The long-term goal is an Education Agent Harness that can be mounted on different model providers and runtimes.
